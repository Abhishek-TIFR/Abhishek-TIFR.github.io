I am an Assistant Professor in the Software Engineering Research Centre (SERC) at IIIT Hyderabad. I primarily work in areas of Formal Methods, Programming Languages, Software Engineering, and Trustworthy AI.

My current research efforts are aimed at establishing a formal foundation for Trustworthy Autonomy in Software Development. In practice that means building theory and tools that let people rely on software they did not write by hand: code produced by language models, concurrent programs running on weak memory hardware, proofs assembled with machine assistance, and robots acting in the physical world.

I am looking for students to join my research group.

BTech, Dual Degree, MS, and PhD students are all welcome. If you are at IIIT Hyderabad and any of the projects below interest you, email me about that project directly — each one has its own link.

Current projects

Trustworthy automated programming

On this projectMeet Parekh, P Sanjana Reddy, Tejaswini Mullapudi

Open toBTech, Dual Degree, MS

Ask about this project

Generative AI has changed how software gets written: a developer describes what they want in plain language and a model produces code. But natural language is ambiguous, so intent can be misread and the resulting program can quietly diverge from the real goal, with no practical way to guarantee functional correctness without human oversight. This project builds frameworks that bridge informal descriptions and rigorous formal specifications, so programmer intent can be stated precisely and AI-generated code verified as part of the development lifecycle rather than trusted on inspection.

Trustworthy concurrency

On this projectHardik Chadha, Nandini Chakaravarthy, Aritra Baksi

Open toDual Degree, MS, PhD

Ask about this project

Parallel computing matters more than ever under AI-driven load, yet parallel programming stays difficult because the weak memory models beneath modern architectures (x86-TSO, POWER, ARM, RISC-V) and languages (C11, RC11) behave unintuitively. Despite decades of work on concurrency semantics, reasoning about concurrent code remains out of reach for most programmers. This project develops largely automated mechanisms for establishing trust in parallel programs, combining program semantics, automated theorem proving, model checking, testing, and fuzzing.

Machine learning for theorem proving

On this projectAkshith Kandagatla, Priyanka Agarwal

Open toBTech, Dual Degree, MS

Ask about this project

Proof assistants have produced remarkable high-assurance software — CompCert, seL4, CakeML — yet formal development stays outside the mainstream, largely because writing and maintaining verified specifications demands so much human effort. This project applies machine learning to cut that cost: making proof search more efficient, automating tactic selection during proof completion, and predicting the hypotheses and intermediate lemmas that carry a proof forward.

Robot motion planning among movable obstacles

Open toBTech, Dual Degree, MS

Ask about this project

Navigation Among Movable Obstacles asks a robot to reach a goal in a cluttered space where it may push, pull, or carry objects out of the way. Because the robot changes the environment as it acts, the search space grows with every object it is allowed to touch. This project looks for planners that come with guarantees rather than empirical success rates: completeness under stated assumptions.
